\# Website Launcher



A simple Python automation tool that checks website HTTP responses and opens websites in your default browser.



\## Features



\- Stores website names and URLs in a Python dictionary.

\- Checks HTTP responses using the `requests` library.

\- Displays HTTP status codes, including `200` and `403`.

\- Handles request failures and timeouts.

\- Opens websites using Python's built-in `webbrowser` module.



\## Technologies Used



\- Python

\- `requests` library

\- `webbrowser` module



\## Requirements



\- Python 3

\- Internet connection

\- `requests` library



\## Installation



Install the required dependency:



python -m pip install requests
